## 括号匹配问题🤯 

这是栈这种数据结构的一个经典应用，
<u>那什么是括号匹配问题呢？</u>

好，那我们先用手算的方式捋一下这个括号匹配的过程。
那这几个括号是不是很简单，
大家可以下意识的看出中间的这两个是一对，最外侧的两个是一对。那这是我们人脑的反应，

如果要用计算机来匹配这些括号的话，那只能一个一个依次扫描，
也就是从左到右扫描，那不难发现这样的一个规律。越往后出现的左括号会越先被匹配，

那算法的这种特性是不是就和栈的后进先出，
我们可以把这些左括号依次压入栈中，
然后越往后压入栈的左括号越先被弹出栈，越先被匹配

![image-20250220163857462](/Users/yuebinghui/Documents/program/github/note/images/image-20250220163857462.png)

来看另一个例子，
每当出现一个右括号的时候，就需要消耗一个左括号，
那这儿的消耗其实是不是就对应了出栈的一个操作

当我们遇到左括号的时候，就把它压入栈中，
当我们遇到右括号的时候，就把栈顶的那个左括号给弹出，然后检查它们俩是否匹配。
这就是大体的思路，

###### 栈在括号匹配中的应用-算法的详细过程 🤯 

我们就来捋一捋这个算法的详细过程
Y是Yes N是No

我们需要从左往右扫描各个括号，那假设此时还有没有被处理的括号？并且我们把当前扫描到的括号记作a，

<u>那接下来是不是需要判断这个a它到底是左括号还是右括号？</u>
*如果是左括号的话*，就需要把它压到栈顶。
然后再接着扫描下一个括号就可以

*如果这个a它不是左括号，而是右括号的话*，
那我们是不是需要弹出栈顶的左括号来检查是否匹配？
而<u>由于栈有可能为空，</u>
<u>所以先要进行一个栈空的判断，</u>
*如果栈直接已经为空了*，那么就说明呃，当前扫描到的这个右括号，它是一个单身的状态。这就意味着，配对失败，就可以直接结束这个算法，

*而如果栈不为空的话，*
那我们可以弹出栈顶的这个左括号。我们用b来表示，
<u>那接下来是不是需要判断b和a是否匹配，</u>
就是小的和小的匹配中的和中的匹配，大的和大的匹配，对吧？
*好，如果发现匹配成功的话，*那是不是就可以接着往后处理下一个括号了？
*而如果匹配失败的话，*同样的我们就可以结束这个算法。

好用这样的方式，是不是可以扫描处理完所有的这些括号
<u>好，所有的这些括号都扫描处理完了之后，我们需要判断栈是否为空。</u>
*如果此时栈非空的话，*那么就说明有一些左括号是没有与它匹配的右括号的
也就说明左括号单身。那这种情况下就是匹配失败，
*而如果栈空的话，*就说明所有的括号都是两两配对的啊，
那此时就是匹配成功。

###### 栈在括号匹配中的应用-代码🤯 

![image-20250220170349186](/Users/yuebinghui/Documents/program/github/note/images/image-20250220170349186.png)

```c++
#include <stdio.h>
#include <stdlib.h>

#define MaxSize 10
#define ElemType char

typedef struct {
    ElemType data[MaxSize];
    int top;
} SqStack;

// 栈代码👇🏻
void InitStack(SqStack &S) {
    S.top = -1;
}

bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) {
        return false;
    }
    S.data[++S.top] = x;
    return true;
}

bool Pop(SqStack &S, ElemType &del) {
    if (S.top == -1) {
        return false;
    }
    del = S.data[S.top--];
    return true;
}

bool StackEmpty(SqStack S) {
    return S.top == -1;
}

bool bracketCheck(SqStack S, char str[], int length) {
    for (int i = 0; i < length; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{') {
            Push(S, str[i]);  // 扫描到左括号，入栈
        } else {
            if (StackEmpty(S))  // 扫描到右括号，且当前栈空
                return false;  // 匹配失败

            char topElem;
            Pop(S, topElem);  // 栈顶元素出栈
            if (str[i] == ')' && topElem != '(')
                return false;
            if (str[i] == ']' && topElem != '[')
                return false;
            if (str[i] == '}' && topElem != '{')
                return false;
        }
    }
    return StackEmpty(S);  // 检索完全部括号后，栈空说明匹配成功
}

int main() {
    SqStack S;
    InitStack(S);
    char str[10] = {'[', '{', '}', ']'};
    printf("bool=%d\n", bracketCheck(S, str, 4));


}
```

###### 总结

用栈来解决括号匹配问题算法思路就是

从左到右依次扫描所有的字符，
*遇到左括号入栈，*
*遇到右括号的话，*弹出栈顶的左括号。检查是否匹配，

如果所有的括号都检查完了，但是最终栈是非空的话，那么说明有左括号单身。

然后如果扫描到右括号，但是此时栈已经空的话，那说明有右括号单身，
而如果弹出的这个栈顶左括号和当前的右括号不匹配的话，
也会出现匹配失败的情况，
