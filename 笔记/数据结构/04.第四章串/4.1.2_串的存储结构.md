串，其实是一种特殊的线性表

我们可以用什么样的存储结构来实现线性表？

同样的就可以用什么样的存储结构来实现串，只不过线性表当中存储的是elemType是某一种数据元素。但是串里边我们把elemtype改成char不就行了

静态数组的缺点呢，是它的长度不可变。如果你二五五这个长度存不下的时候，想要拓展它，那就是不可能的

课本当中把它称为定长的顺序存储

那如果想让它可变长的话，我们就可以用动态数组的方式来实现，也就是在你的结构体里边定义一个。一个这样的基地址的指针，然后用my lock来申请一整片的连续的存储空间，让你的基地址指针指向这一片空间的起始地址

那之前我们说过my lock函数申请的这一片内存空间是属于内存里边的堆区

所以我们的课本上把这种实现方式称为堆分配存储，其实它就是一个动态数组，那堆区的这一片内存空间，你需要手动的free，也就是调用free函数。把这一片空间给释放回收

用上面这种方式实现的话，那给你分配的这一片存储空间是会由系统自动的回收的。当你的函数执行结束之后，这一片空间就会被自动回收

## 串的链式存储

接下来看串的链式存储，其实和线性表也是一样的

不过需要注意的是我们这儿一个char，它的大小只有一个字节。但是在32位的计算机当中，指针大小应该是32个比特，也就是四个字节。所以这就意味着你用一个字节的空间存储你实际想要的这个信息，还要用四个字节的空间来存储一个辅助的信息那。那这种情况我们可以把它称为存储密度低，也就是实际有用的信息所占的比例非常小

#include <stdio.h>

#define MaxLen 255
typedef char ElemType;
typedef struct {
    ElemType ch[MaxLen];
    int length;
} SString;

void StrAssign(SString &T, char chars[]) {
    int i = 0;
    while (chars[i]) {
        T.ch[i + 1] = chars[i];
        i++;
    }
    T.length = i;
}

// 求子串。用Sub返回串S的第pos个字符起，长度为Len的字串
void SubString(SString &Sub, SString S, int pos, int len) {
    if (pos + len - 1 > S.length) {
        return;
    }
    for (int i = pos; i < pos + len; i++) {
        Sub.ch[i - pos + 1] = S.ch[i];
    }
    Sub.length = len;
}

int StrCompare(SString S, SString T) {
    for (int i = 1; i <= S.length && i <= T.length; i++) {
        if (S.ch[i] != T.ch[i]) {
            return S.ch[i] - T.ch[i];
        }
    }
    return S.length - T.length;
}

int StrLength(SString S) {
    return S.length;
}

int Index(SString S, SString T) {
    int i = 1, n = StrLength(S), m = StrLength(T);
    SString sub;
    while (i <= n - m + 1) {
        SubString(sub, S, i, m);
        if (StrCompare(sub, T) != 0) {
            i++;
        } else {
            return i;
        }
    }
    return 0;
}
