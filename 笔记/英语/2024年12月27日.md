# 精度加真题长难句建议

1精读要求逐字逐句翻译出来，你自己翻译一遍，然后对着译文看一下自己问题在哪儿，
通过这个过程去积累生词，培养阅读能力，同时更深更精准的把握这个词的意思

❤️要求手译的目的:因为脑子知道是一方面，要写出来还有一道灵活处理过程，这个过程很重要，关系到句子的组织、词的把握等

## 背诵句子

It is fairly clear that the sleeping period must have some function, and because there is so much of it the function would seem to be important.

很明确的是，睡眠期必定有一定的功能，而且因为睡眠占据了大量的时间，这
个功能似乎很重要。

It is fairly clear that the sleeping period must have some function, and because there is so much of it the function would seem to be important.



If it is not a question of resting the body, then perhaps it is the brain that needs resting?
如果这不是为了休息身体，那么也许是需要让大脑休息？

it is ... that 强调句
If it is not a question of resting the body, then perhaps it is the brain that needs resting?



there is so much of it: 这里的 it指的是睡眠。这句话的意思是睡眠占据了我们生活中很大一部分时间。

he function would seem to be important: 这里的 function指的是睡眠的功能。would seem to be 是一个表达可能性的短语，意味着从逻辑上推断，睡眠的功能应该是重要的。

整句话的意思：由于睡眠占据了我们生活的很大一部分时间，我们可以推断出睡眠的功能是重要的。这是一个基于睡眠所占时间比例的逻辑推断。
